This project was made as a solution to a problem Statement proposed by us in a competition named Innomax (By Thermax PVT. LTD.). The model 
was trained using actual operation data from multiple sensors installed on the industrial boiler.The Novel thing about this is that it uses 
an AI model to predict the next boiler states given the current states and desired control input. Unlike the approaches in the literature 
where they predict only few states and assuming that the rest as barely changing, which fails when it comes to real industrial boilers. This
was presented on the finale of the competition among the top 11 from 200 colleges across India.
